# Post-update verification checklist

- [ ] Confirm `git status` lists only README, docs/README and Assignment 5 presentation additions.
- [ ] Run `cd pathfinder/backend && npm ci && npm test`.
- [ ] Confirm the frontend remains unchanged.
- [ ] Check slide deck against class diagram and actual modules.
- [ ] Export Presentation #2 from Drive after team confirmation.
- [ ] Export reports Weeks 6–8 after team confirmation.
- [ ] Agree on canonical requirements version before replacing the old one.
- [ ] Review DB iteration files for passwords, connection URIs, service-role keys and private data before committing.
- [ ] Merge via PR after a teammate reviews the diff.

This update intentionally does **not** claim that unexported Drive items were uploaded.
